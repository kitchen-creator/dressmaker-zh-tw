## 補丁內容

- 5,372 筆繁體文字，其中包含 3,163 句對話；用語採「裁縫師」「早安」「工作」等台灣習慣。
- 人名沿用遊戲英文拼寫，10 位主要角色在首次主線委託介紹時附名字小註。小註依原任務進度出現，已讀過的介紹不會重新播放；重播同段介紹時可能再次出現。
- 主選單標題「針影裁夢」、新品海報，以及報頭「茶餘小報／一盞閒茶，滿紙熱聞」改為繁體。
- v1.7 修訂 46 句問候語與工作用語。圖片上的字使用 imagegen 編修，字形與原版略有不同；原人物與插畫保留。其他尚未處理的圖片可能仍有簡體字。

## 安裝

1. 先在遊戲中儲存，並完整退出 Dressmaker。
2. 下載 ZIP，將整個資料夾解壓到「文件」等可寫入的位置；保留資料夾內所有檔案。
3. 雙擊「安裝補丁.command」。工具會尋找 Steam 安裝目錄；找不到時，依提示選擇 `Dressmaker.app`。
4. 等待顯示安裝完成，再啟動遊戲，將遊戲語言選為「中文」。

公開包使用 4 個差分檔，需搭配上述版本的原版資源；不含完整遊戲檔案、個人存檔或遊玩紀錄。

若 macOS 阻擋安裝工具，在確認下載來源後，可依 [Apple 官方說明](https://support.apple.com/zh-tw/102445)，先嘗試開啟，再到「系統設定」→「隱私權與安全性」按「強制打開」，並確認「打開」。按鈕名稱可能隨系統版本不同。

## 還原與更新

安裝工具會將原版資源備份到遊戲 App 同一層的 `.dressmaker-zh-tw-backup-v1.7` 資料夾。請保留備份。

要還原時，先完整退出遊戲，再雙擊「還原原版.command」。安裝與還原均不改動存檔。

Steam 更新或驗證遊戲檔案可能覆蓋補丁。若版本已變更，請等待對應版本的補丁；不要強行套用舊版差分。
